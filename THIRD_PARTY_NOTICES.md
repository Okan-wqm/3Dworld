# Third-Party Notices

This file will reproduce the copyright notices, license texts and NOTICE files of all third-party components used by 3Dworld, as required by their licenses (MIT, Apache-2.0, BSD and others).

It is generated automatically (`cargo-about` for Rust crates, `license-checker` for npm packages, `pip-licenses` for Python packages, plus the license files of the model weights listed in `weights/allowlist`). Generation will be wired up in Phase 0; until then no third-party code is included in this repository.

See [`LICENSES.md`](LICENSES.md) for the curated registry of approved, pending and forbidden components.
